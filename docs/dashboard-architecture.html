Architecture & Mapping Design

ChitChat Bot — Dashboard

Go + Wails v2 desktop dashboard. এই পোস্টারটা দেখায় ড্যাশবোর্ড কতগুলো স্তরে গঠিত, প্রতিটা বাটন কোন Go function-এ যায়, data কোথায় থাকে, আর event কীভাবে ফিরে আসে। কোনো source code পরিবর্তন করা হয়নি — এটা reference design।

09

Design invariants · ভাঙা যাবে না

এই নিয়মগুলো কোড-কমেন্ট, AGENTS.md আর docs/ থেকে নেওয়া — নতুন feature যোগ করার সময় এগুলোর বাইরে যাওয়া যাবে না।

01Credential কখনো log-এ যাবে না। applog.Redact + frontend শুধু error stack পাঠায়, invocation args নয়।
02Message render-এ innerHTML নয়। শুধু textContent + pre-wrap — message-এ markup থাকতে পারে।
03Clean শুধু data/ এর ভিতরে। প্রতিটা target pathInside() দিয়ে যাচাই হয়।
04Show Mode = DOM-only। কোনো WebSocket frame বা undocumented API নয় — শুধু যা human দেখে।
05Bot running থাকলে Clean blocked (backend error + UI disabled)।
06Settings refresh unsaved form মুছবে না। browserFormLoaded guard।
07Proxy assignment deterministic — index % n, random নয়; তাই restart-এ একই worker একই proxy পায়।
08Temp browser data repo-র বাইরে এবং প্রতিটা path-এ cleanup defer করা।
09Stats-এর একমাত্র source bot_state.json। UI নিজে কোনো count অনুমান করে না।

Known gaps · এখনো ঠিক করা হয়নি

কোড অপরিবর্তিত — এগুলো শুধু চিহ্নিত। কোনটা আগে ধরব, সেটা আপনার সিদ্ধান্ত।

A1cmd/chitchatui/ পুরনো duplicate। root app.go-তেই আসল dashboard (license, live chat, TestProxyEntries)। ওই folder build করলে ভাঙা UI হবে — root build ঠিক আছে।MEDIUM
A2License key enter করার path নেই। input readonly, শুধু Copy — invalid হলে user নিজে কিছু করতে পারে না।MEDIUM
A3License verify single point of failure। remote API down হলে app overlay-এ আটকে যায় — offline grace নেই।MEDIUM
A4live_chat flag persist হয়ে থাকে। Show Mode শেষ হলেও saved browser settings-এ থেকে যায়।LOW
A5প্রতি 3s-এ পুরো UISnapshot। settings + 200 log টানা হয়, অথচ দরকার শুধু stats।LOW
A6RunFreshBrowsers binding unused। UI RunBrowser ব্যবহার করে — dead API।LOW
A7bot_accounts = max(workers, running+dead)। Dead account worker count-এ ধরা হয় না → সংখ্যা বিভ্রান্তিকর হতে পারে।LOW
A8প্রতি poll-এ সব bot_state.json পড়া হয়। profile বেশি হলে CPU খরচ বাড়ে — cache দরকার।LOW
